How this system learns today

PROJECT_EVIDENCE is produced only by actual NP01–NP04 executions. A DERIVED_OBSERVATION normalizes a known run for comparison; it is not domain authority.

The active analysis is DETERMINISTIC DESCRIPTIVE: feature summaries, run-to-run differences and bounded rule indications. It is not machine learning, prediction, diagnosis or automated decision authority.

project evidence → derived observations → deterministic descriptive analysis → human interpretation

Human feedback is retained separately and never triggers automatic retraining.

VAE — concept demonstration

Status: CONCEPT_DEMONSTRATION · trained: NO

A future VAE could learn what compatible historical runs tend to look like within one domain and highlight a materially different pattern. It would indicate difference from observed patterns, not whether a run is correct, safe or unsafe.

Why not trained: the current set has one observation per project, which is insufficient for defensible representation learning. No rows are fabricated.

Bounded example (NP02, example only): compare accepted, quarantined and rejected ratios, quality outcomes, lineage status and KPI status.

NP02 history → compatible feature vectors → VAE encoder → latent representation → reconstruction → reconstruction difference → anomaly signal → human inspection
