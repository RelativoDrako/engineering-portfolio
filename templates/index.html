How to use this surface

  1. Open a project to read its purpose, prerequisites and latest result.
  2. Operate only a registered project action, then inspect the linked evidence bundle.
  3. Record explicit feedback and open Learning for the current descriptive analysis and future model concepts.

Today the comparisons are deterministic and inspectable. VAE and GAN are shown only as conceptual extensions; neither is trained or operational, and neither can replace project evidence or human authority.

The portfolio surface is an integration and operator view. It stores references and bounded derived observations in its own local SQLite store; it does not copy run bundles or replace project domain authorities.
